# 자/모음 분리 복구기

맥에서 보낸 한글 파일·폴더 이름이 윈도우에서 `ㅂㅗㄱㅗㅅㅓ.docx`처럼 자음·모음이 풀어져 보이는 것을 한 번에 고치는 도구입니다.

- **브라우저 버전**: 파일을 서버로 보내지 않고 브라우저 안에서만 고칩니다. (준비 중)
- **윈도우 프로그램**: 폴더를 고르면 안의 이름을 모두 고치고, 되돌리기 목록(CSV)을 남깁니다. (준비 중)

## 왜 이런 일이 생기나

맥은 한글 이름을 자음·모음으로 나눠(NFD) 저장하고, 윈도우는 합친 글자(NFC)를 기대합니다. 이 도구는 이름을 **NFC로 바꾸는 것** 하나만 합니다. 고치기 전에 바뀔 이름을 먼저 보여 주고, 같은 이름이 이미 있으면 건너뜁니다.

## 개발

- 고치기 규칙의 기준 사례: `testdata/cases.json` (Go·JavaScript 구현이 함께 씁니다)
- 만들면서 겪은 일: `docs/trials/`
