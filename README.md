# 자/모음 분리 복구기

맥에서 보낸 한글 파일·폴더 이름이 윈도우에서 `ㅂㅗㄱㅗㅅㅓ.docx`처럼 자음·모음이 풀어져 보이는 것을 한 번에 고치는 도구입니다.

- **브라우저 버전**: https://jwkim1421.github.io/hangul-name-fixer/ — 파일을 서버로 보내지 않고 브라우저 안에서만 고칩니다.
  - 고친 ZIP 받기: 모든 브라우저. 파일·폴더·ZIP을 넣으면 이름을 고친 ZIP을 내려받습니다.
  - 폴더 바로 고치기: Chrome·Edge. 폴더 안 이름을 그 자리에서 고칩니다.
- **윈도우 프로그램**: 폴더나 파일(여러 개)을 선택하면 이름을 고칩니다. 원하면 원래 이름을 적은 수정 목록(CSV)을 남깁니다. (준비 중 — 윈도우 실행 파일과 바이러스 검사 결과를 함께 올릴 예정)

## 왜 이런 일이 생기나

맥은 한글 이름을 자음·모음으로 나눠(NFD) 저장하고, 윈도우는 합친 글자(NFC)를 기대합니다. 이 도구는 이름을 **NFC로 바꾸는 것** 하나만 합니다. 고치기 전에 바뀔 이름을 먼저 보여 주고, 같은 이름이 이미 있으면 덮어쓰지 않고 이름 끝에 (1), (2)를 붙입니다.

## 개발

- 테스트: `cd core && go test ./...` (Go 규칙), `cd web && node --test` (브라우저 규칙). GitHub Actions가 윈도우·맥에서 함께 돌립니다.

- 고치기 규칙의 기준 사례: `testdata/cases.json` (Go·JavaScript 구현이 함께 씁니다)
- 만들면서 겪은 일: `docs/trials/`
